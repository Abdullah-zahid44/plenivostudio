# Quick Start — Ultimate Offline Life Planner (5 minutes)

## 1. Open the planner (30 seconds)

Extract the ZIP, then double-click `ultimate-life-planner.html`.
It opens in your browser like any web page.

## 2. Take the onboarding tour (2 minutes)

On first launch you will see a short walkthrough of the main sections.
You can also load **optional sample data** to explore with — it is clearly
marked as sample content and you can delete it at any time from Settings.

Tip: skip the tour with the close button; reopen it anytime from the Help panel.

## 3. Add your first task (1 minute)

1. Go to **Tasks** in the sidebar.
2. Click **Add task**, type something real (e.g. "Pay electricity bill"),
   set a due date and priority, then save.
3. Click the checkbox next to it to mark it done. Done tasks stay visible
   until you delete them.

## 4. Start a habit (1 minute)

1. Go to **Habits** → **Add habit**.
2. Name it (e.g. "Read 10 pages"), save, then tap today's dot to log it.
3. Come back daily — your streak counter keeps you honest.

## 5. Make your first backup (30 seconds)

1. Go to **Settings** → **Export**.
2. Save the downloaded JSON file somewhere safe (cloud drive, USB stick).
3. That's it. Repeat weekly, or before clearing browser data.

Repeat step 5 on any device where you use the planner. Your data lives in
the browser on each device — there is no sync between devices, so export
from one and import on the other if you switch.

## Next steps

- **Daily:** check the **Today** dashboard each morning for priorities and habits.
- **Weekly:** review the **Weekly** view every Sunday (or your chosen week-start day).
- **Monthly:** use the **Budget** tab to log income and expenses; the bar chart
  shows your month at a glance. (Informational only — not financial advice.)
- **Journal:** end the day with a dated entry and an optional mood tag.

Stuck? Open the in-app Help panel (`?`) or see `BROWSER-SUPPORT.md` for
browser-specific notes.
